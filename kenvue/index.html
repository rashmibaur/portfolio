A self-service tool that empowers planners with live, flexible, and shareable data views, turning raw supply-chain data into clear insights that elevate decision quality and speed.

The problem

Fragmented, manual, and stale

Planners across demand, supply, S&OP, logistics, and replenishment rely on custom tables to plan and collaborate – yet today's workflow is entirely manual and disconnected.

No unified view

No consistent way to assemble a table across multiple datasets in one place.

Manual transforms

Planners export raw data to Excel, build tables by hand, and email files back and forth.

Lost freshness

Data lineage, auditability, and auto-refresh are absent, eroding trust in shared outputs.

No access control

Sharing lacks role-appropriate permissions, creating risk and inconsistency across teams.

Users

Three planners, one tool

Each planner starts from a different question, but all of them were building the same table by hand.

01
Forecasts demand

Demand planner

Builds accurate forecasts from historical trends, promotions, sales inputs and market intelligence, across SKU and category hierarchies.

Today

  • Manual table creation spanning multiple systems
  • Hard to track forecast changes across versions
  • Needs fast pivots and drill-downs during live meetings

With the table builder

  • Compare forecast snapshots (Bias %, APE, uplift)
  • Live, shareable views for cross-functional alignment
  • Auto-refreshing tables for weekly demand reviews
02
Balances supply and demand

Supply planner

Balances supply against demand and builds feasible supply plans from ERP, production and planning data.

Today

  • Fragmented data across ERP, production and planning tools
  • Time-consuming manual consolidation before S&OP
  • Slow access to updated supply run snapshots

With the table builder

  • Merge supply plan, demand and inventory datasets
  • Gap calculations (Supply − Net Demand) on the fly
  • Snapshot-based comparisons of supply plan runs
03
Keeps stock at the right level

Inventory planner

Keeps inventory right across DCs and stores, watching days on hand (DOH) and service levels every day.

Today

  • Hard to combine demand, inventory and in-transit data in one view
  • Stale data leads to poor replenishment decisions
  • Manual conditional formatting to flag risks

With the table builder

  • Build “Inventory Health” tables quickly, with conditional formatting
  • Real-time on-hand and in-transit metric views
  • Easy sharing for daily standups and replenishment calls

Context

Platform context

The Custom Table Builder sits within a broader end-to-end supply chain planning platform used by FMCG organisations. It acts as a core data exploration and decision-support layer spanning demand, supply, and inventory workflows.

Snap

When was it captured?

When a number was captured or predicted. Lets planners compare versions and track forecast accuracy.

ExamplesJan forecast made Dec 1 vs Dec 15 vs Jan 1 · End of day vs start of planning cycle · Before vs after sales adjustment

Measures

What is changing?

The numbers that move over time and drive decisions.

ExamplesForecast quantity · Net demand (forecast − inventory) · Actual sales / shipments · Supply quantity

Dimensions

How is it sliced?

The stable categories that slice the data, for filtering, pivoting and rollups.

ExamplesProduct (SKU, brand, category, franchise) · Geography (region, country, market, cluster) · Supply node (plant, warehouse, DC) · Customer / channel

Time

When is it happening?

The calendar or fiscal period a number belongs to, from weeks to quarters.

ExamplesYear (FY2024, FY2025) · Quarter (Q1, Q2) · Month (January, February) · Rolling (last 4 weeks, next 3 months)

Feature 01 of 06

Field selection (measures, dimensions, time)

Allows users to select and configure core data elements measures, dimensions, and time forming the foundation of the table.

Interaction

  • Browse categorized Measures (demand, supply, inventory)
  • Select Dimensions (brand, region, site, etc.)
  • Choose Time formats (monthly, weekly, yearly)
  • Switch between standard vs current time
  • Select multiple fields

How it helps users

  • Enables flexible data composition across planning functions
  • Supports multi-dimensional analysis
  • Reduces dependency on predefined reports

Feature 02 of 06

Drag-and-drop table structuring

Interactive table-building where users arrange selected fields into rows and columns.

Interaction

  • Drag fields intoRowsColumns
  • Reorder hierarchy
  • Group dimensions

How it helps users

  • Makes table creation intuitive and visual
  • Enables quick restructuring during analysis
  • Supports hierarchical exploration (SKU → brand → region)

Feature 03 of 06

Filter management system

A flexible filtering system to refine data based on user-defined criteria.

Interaction

  • Add filters via dialog
  • ChooseSpecific valuesCurrent values
  • Switch betweenSingle-selectMulti-select
  • View filters as chips
  • Edit / remove filters

How it helps users

  • Allows users to focus on relevant data slices
  • Supports scenario-based analysis
  • Improves readability and reduces clutter

Feature 04 of 06

Subtotals configuration

Enables users to add subtotal calculations across rows or columns.

Interaction

  • Open subtotal panel
  • ChooseMeasuresSelected valuesStandard values
  • Apply at specific hierarchy levels

How it helps users

  • Provides aggregated insights instantly
  • Reduces need for manual calculations
  • Helps in summarizing large datasets

Feature 05 of 06

Delta analysis (comparisons)

Allows users to compute differences (delta) between selected rows or columns.

Interaction

  • Select fields for comparison
  • DefineValue typeComparison level
  • Apply delta to rows or columns

How it helps users

  • Enables quick identification of gaps and trends
  • Critical forForecast vs actual comparisonSupply vs demand gap analysis
  • Supports decision-making during reviews

Feature 06 of 06

Drill down / drill up (time-based)

Allows users to navigate across time hierarchies for deeper insights.

Interaction

  • Drill fromYear → Quarter → Month → Week
  • Only enabled when time dimension is present

How it helps users

  • Enables progressive data exploration
  • Helps identify patterns across time levels
  • Crucial for demand and inventory trend analysis
